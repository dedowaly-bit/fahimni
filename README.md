# فهمني — Fahimni 🎓

منصة تعليمية عربية متكاملة (RTL) تعمل على **كل الأجهزة** — موبايل، تابلت، وكمبيوتر —
مبنية بـ HTML/CSS/JS خالص بدون أي مكتبات أو خطوات بناء.
**تنطلق فارغة تمامًا من أي محتوى وهمي** — كل كورس وكل رقم ناتج عن استخدام فعلي 100%.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل أي خادم ثابت:

```bash
npx serve .
# ثم افتح http://localhost:3000
```

- الإدارة تملك سيطرة كاملة: قبول/رفض المدرسين، إيقاف/تشغيل أي حساب، إدارة الكورسات والأقسام والمعاملات والإعلانات والإعدادات وإعادة تعيين المنصة.

## أبرز المزايا الحقيقية
- **📷 صورة فاتورة التحويل إجبارية** — يُرفق الطالب صورة الفاتورة (إنستاباي أو إيصال حقيقي) مع كل طلب شحن، تُعرض للإدارة مع إمكانية التكبير.
- **🎯 امتحان من أخطائك** — عند ارتكاب أي خطأ في أي اختبار، يُولَّد امتحان خاص من كل الأسئلة الخاطئة فقط. الحل الصحيح يُخرج السؤال من البنك نهائيًا.
- **📸 صور في الاختبارات** — المدرس يرفع صورة لكل سؤال (نظام مستر محمد صلاح: صورة السؤال ثم الإجابات تحتها).
- **🎨 هوية رصاصية موحّدة** — ألوان أبيض ورمادي مع شعار فهمني على كل الصفحات.
- **📉 تحديث آمن لا يمسح البيانات** — ترحيل تلقائي من النسخ القديمة مع الحفاظ الكامل على كل الحسابات والأرصدة.
- **💬 شات داخلي** بين الإدارة والمدرسين داخل المنصة مع عدّاد غير المقروء.
- **📱 استجابة كاملة** — يعمل بكفاءة على الكومبيوتر والموبايل مع قوائم جانبية وأزرار هامبرغر.
- **رقم ولي الأمر إجباري** لكل طالب بصيغة مصرية صحيحة (01xxxxxxxxx).

## البنية
```
index.html          الهيكل الوحيد (SPA)
css/style.css       نظام التصميم RTL + استجابة + هوية رصاصية
js/app.js           الراوتر + الأحداث العامة + الشات الداخلي
js/data/seed.js     حالة الإقلاع النظيفة (مدير + أقسام فقط)
js/core/db.js       طبقة تخزين مجمّعة (fahimni:v5:*) مع ترحيل آمن
js/core/api.js      منطق الأعمال — نقطة الاستبدال الوحيدة لـSupabase
js/core/auth.js     المصادقة والأدوار + قواعد ولي الأمر وفريدية المدير
js/core/ui.js       مكوّنات الواجهة + ضغط الصور
js/pages/*          الصفحات: عامة / مصادقة / طالب / معلم / إدارة
assets/logo.svg     شعار المنصة (كتاب + مصباح + فهمني)
tests/*.test.js     4 مجموعات اختبار (118+ إجراء)
```
